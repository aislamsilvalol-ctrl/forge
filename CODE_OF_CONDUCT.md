# Code of Conduct

## Our standard

Be direct about code and respectful about people. Technical disagreement is
welcome and expected; personal attacks, harassment and discriminatory
language are not.

Assume competence. Explain reasoning rather than asserting authority. When
you are wrong, say so — that is how a codebase that moves money stays honest.

## Scope

Applies to issues, pull requests, discussions and any space representing the
project.

## Enforcement

Report unacceptable behaviour through a private security advisory or by
contacting the maintainers. Reports are handled confidentially. Maintainers
may remove content, or block accounts, that violate this standard.

Adapted in spirit from the Contributor Covenant.
